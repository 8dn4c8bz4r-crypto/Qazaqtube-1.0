QazaqTube — сервері бар демо жоба

ІСКЕ ҚОСУ:
1. Компьютерге Node.js орнат.
2. Осы буманы аш.
3. Терминалда осы бумаға кір.
4. npm install
5. npm start
6. Браузерден http://localhost:3000 аш.

МҮМКІНДІКТЕР:
- Видео файлдарды сервердің uploads/ бумасына жүктеу
- Видео тізімі data/videos.json ішінде сақталады
- Shorts бөліміне видео жүктеу (жүктеу кезінде Shorts белгісін қою)
- Видео ойнату, іздеу, категория, лайк

ЕСКЕРТУ:
Бұл — іске қосуға дайын бастапқы демо. Интернетке бәріне ашық жариялау үшін хостингке орналастыру керек.
Қазіргі нұсқада аккаунт/кіру, пікірлер, авторизация және бұлттық сақтау жоқ.
Жүктеу шегі: 200 MB. Нақты хостингке шығарғанда HTTPS, пайдаланушы аккаунты, файлдарды тексеру және тұрақты сақтау орнын қосу керек.
